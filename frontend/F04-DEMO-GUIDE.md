# AutoLog 시연 가이드 · F03/F04

권장 녹화 크기는 1280×720 또는 1920×1080입니다. 21:9 화면은 1680×720으로 확인했습니다.

## 실행

`index.standalone.html`을 Chrome/Edge에서 엽니다. 개발 소스를 시연하려면 `npm run dev` 실행 후 `http://localhost:3000`에 접속합니다. 의존성 설치는 필요하지 않습니다.

## 80초 시연

| 시간 | 조작 | 확인할 내용 |
| --- | --- | --- |
| 0–12초 | 최초 실행 화면에서 소개와 MOCK DATA 배지를 보여준 뒤 **모의 주행 시연 시작** | 모의 차량 데이터이며 실제 위치/차량에 연결하지 않았음 |
| 12–30초 | 주행 화면의 큰 수치와 오른쪽 타임라인 제시 | 총 12.0km · 실제 운행 35분. 구간 1은 5km/15분, 구간 2는 7km/20분. 08:15–08:25의 정차 10분은 제외 |
| 30–47초 | **주유 기록 확인** | 30% → 75%, +45%p, OBSERVED. 주유량과 결제금액은 미확인, UNKNOWN · null. 사건 상태는 DETECTED_UNCONFIRMED |
| 47–65초 | **금액 정정하러 가기** → 기본 65,000원 확인 → **정정 적용** | 현재 금액이 65,000원 / USER_INPUT으로 변경. 이전 null/UNKNOWN과 새로운 값이 correction-1에 분리 보존 |
| 65–73초 | 주유 화면에 재진입 → 조회·정정으로 돌아와 원본과 이력 제시 | 65,000원/USER_INPUT 유지. 원본 e03/e05=30%, e07=75% 유지. 주유량은 미확인, 사건 상태는 자동 확정되지 않음 |
| 73–80초 | 하단 **초기화** | 최초 화면 · Step 0/11 · 08:00 복귀. 정정 이력과 수집 데이터도 비워짐 |

## 입력 잠금 추가 시연

1. 초기화 후 하단 **다음 이벤트**를 8번 누릅니다.
2. Step 8/11, e08 IGNITION=ON, 08:25를 확인합니다. 첫 구간만 집계되므로 **5.0km / 15분**입니다.
3. 왼쪽 **조회·정정**에서 입력·키패드·적용이 잠기는 것을 보여줍니다.
4. **전체 실행**으로 e11까지 진행합니다. 시동 OFF가 되면 입력이 해제됩니다.

현재 Fixture에 속도/기어 신호가 없어 시동 OFF를 입력 허용 조건으로 사용합니다. 이 시연을 실제 차량의 주행 판별이나 안전 규격 인증으로 설명하지 않습니다.

## 확인 명령

```powershell
npm test
npm run build
```

팀 B04의 고정 버전 F01을 실제 계산 파이프라인에 넣습니다. 중복·공백·EV 추가 검사는 `npm test`에 포함되어 있고, 네 화면 촬영은 ICE F01을 사용합니다. 새로고침과 초기화는 메모리의 시연 기록을 지웁니다. 영구 저장/복구 완료로 설명하지 않습니다. UI 또는 코어 소스를 수정한 뒤에는 `npm run build`로 단독 파일을 다시 생성합니다.

## F04 제출 상태

- 촬영 가능한 브라우저 Mock 앱과 실행 안내: 준비됨.
- 정정 후 화면 재진입/유지 및 Reset: 촬영에 포함.
- 최종 녹화 영상: 아직 생성하지 않음. 시연자가 녹화 후 PM에게 전달.
- 소스 공유 URL: 아직 원격 업로드/확인하지 않음. 준비된 소스 ZIP으로 전달 가능.
- APK: 조건부 선택 항목. 이번 웹 번들을 APK라고 기재하지 않음. 실제 Android release 빌드와 실행 증거가 확보되면 별도로 제출.

범위 판정의 근거와 후속 P0 미구현 항목은 `docs/F03-F04-REVIEW.md`에 정리했습니다. 공모전 최종 제출양식은 PM/B02가 다시 확인합니다.

자동 브라우저의 file:// 접근 제한 때문에 단독 파일은 HTTP에서 실행 검증했습니다. 자세한 검증 범위는 README.md를 참고하세요.
